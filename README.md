# AirSense-Urban-Air-Quality-Risk-Prediction-
 Analyzed 5 years of real CPCB air quality data across 26 Indian cities to build a custom health-risk scoring model. Built a Random Forest classifier (82% accuracy) to identify pollution risk categories and a forecasting model (R² 0.91) to predict next-day AQI, with pollutant-trend visualizations highlighting the highest-risk cities and seasons.
